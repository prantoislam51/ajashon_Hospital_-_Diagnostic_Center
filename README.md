# Rajashon Hospital & Diagnostic Center — Astro 7

Node.js 22.23.4+ লাগবে।

    npm install
    npm run dev      # http://localhost:4321
    npm run build    # dist/

## ফিচার
- ডিফল্ট ইংরেজি; হেডারের "বাংলা" বাটনে বাংলা (পছন্দ মনে থাকে)
- Day / Night মোড (☾/☀), সম্পূর্ণ responsive, মোবাইলে মেনু বাটন
- ছবির গ্যালারি + বর্ণনা, ডাক্তার তালিকা/প্রোফাইল, টেস্ট ও মূল্য, অ্যাপয়েন্টমেন্ট (WhatsApp), যোগাযোগ

## আপনার ছবি বসানো
`public/images/` ফোল্ডারে নিজের ছবি দিন (যেমন `gallery-1.jpg`), তারপর `src/data/center.js`-এর `gallery` অংশে
`src` ও বাংলা/English ক্যাপশন বদলান।

## তথ্য বদলানো
সব তথ্য `src/data/center.js` ফাইলে (en/bn জোড়ায়)।
- আসল (ছবি থেকে): নাম, সিরিয়ালের ফোন, ঠিকানা, ইমেইল
- নমুনা: ডাক্তার, ডিগ্রি, BMDC, সময়, টেস্ট ও মূল্য, প্যাকেজ, খোলার সময়, লাইসেন্স, ক্যাপশন
- `whatsapp` নম্বর ও ইমেইল নিশ্চিত করুন
- তথ্য আসল হলে `Base.astro` থেকে ডেমো ব্যানার (`.demo`) সরান
